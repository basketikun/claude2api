统一接口说明

兼容 OpenAI、Anthropic 客户端，服务会自动轮询号池账号并在失败时切换。

Base URL—
OpenAI 鉴权Authorization: Bearer <号池密钥>
Anthropic 鉴权x-api-key: <号池密钥>

模型支持 -thinking 后缀开启扩展思考，例如 claude-sonnet-4-5-thinking。

POST/v1/chat/completions

OpenAI Chat Completions 兼容接口，支持流式输出。

请求参数

modelstring · 必填模型名称messagesarray · 必填角色与内容数组streamboolean · 可选是否以 SSE 流式返回temperaturenumber · 可选采样温度

响应

{ "id": "chatcmpl-...", "choices": [{ "message": { "role": "assistant", "content": "..." } }] }
POST/v1/responses

OpenAI Responses API 兼容接口，适用于新一代 OpenAI SDK。

请求参数

modelstring · 必填模型名称inputstring / array · 必填用户输入内容streamboolean · 可选是否流式返回

响应

{ "id": "resp_...", "object": "response", "output": [{ "type": "message", "content": [{ "text": "..." }] }] }
POST/v1/messages

Anthropic Messages 兼容接口，可直接复用 Claude SDK。

请求参数

modelstring · 必填模型名称max_tokensinteger · 必填最大输出 token 数messagesarray · 必填对话消息数组streamboolean · 可选是否流式返回

响应

{ "id": "msg_...", "type": "message", "role": "assistant", "content": [{ "type": "text", "text": "..." }] }
GET/v1/models

获取当前服务可用的模型列表。

请求参数

无—仅需携带鉴权请求头

响应

{ "object": "list", "data": [{ "id": "claude-sonnet-4-5", "object": "model" }] }
